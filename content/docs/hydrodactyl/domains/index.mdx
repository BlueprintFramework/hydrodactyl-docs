---
title: Domains
description: Give game servers a domain name instead of an IP address and port.
---

Hydrodactyl can create DNS records for game servers, so players can join with a
name such as `play.example.com` instead of an IP address and port.

There are two ways to do this:

- **Subdomains**: an administrator adds a domain in
  **Admin -> Settings -> Domains** with one of the supported DNS providers. Server
  owners then pick a subdomain of it, for example `survival.example.com`.
- **User Domains**: server owners point a domain they own, on their own Cloudflare
  account, at their Minecraft server.

A server can have one subdomain and one user domain at the same time.
