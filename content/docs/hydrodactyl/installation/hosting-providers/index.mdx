Hydrodactyl can be deployed on a managed hosting platform instead of setting everything up by hand. The guides below walk through the platform-specific setup.

<Callout type="note">
  These integrations are community-maintained unless noted otherwise. The
  Hydrodactyl team is happy to help with the panel itself, but issues specific to
  a provider's template or platform should be raised with that provider.
</Callout>
