title: Egg Features

Hydrodactyl eggs can declare **features** — special entries in the egg's `features` array. When the panel sees a feature it recognises, it enables the matching UI, DNS record, or installer for that server.

## Minecraft mod & plugin installer

Hydrodactyl ships a built-in installer for Minecraft mods and plugins. Servers whose egg has a `mod/` or `plugin/` feature get an **Installer** tab, where users can search supported marketplaces and install releases. The panel resolves the download and has the daemon pull the file straight into the server's `mods/` or `plugins/` folder.

| Source   | Content             | Website                                               |
| -------- | ------------------- | ----------------------------------------------------- |
| Modrinth | Mods and plugins    | [modrinth.com](https://modrinth.com/)                 |
| Hangar   | Plugins (PaperMC)   | [hangar.papermc.io](https://hangar.papermc.io/)       |
| Spigot   | Plugins (SpigotMC)  | [spigotmc.org](https://www.spigotmc.org/resources/)   |

Enable the installer for an egg by adding a loader feature:

- `mod/<loader>` installs into the server's `mods/` folder
- `plugin/<loader>` installs into the server's `plugins/` folder

The value after the prefix is the loader name. Hydrodactyl normalises common aliases (for example `neo_forge` → `neoforge`) and validates the loader against the marketplace's live loader list, so a typo won't offer content that can't actually run.

### Examples

`mod/fabric` · `mod/forge` · `mod/neoforge` · `mod/quilt`

`plugin/paper` · `plugin/purpur` · `plugin/spigot` · `plugin/sponge` · `plugin/bungeecord` · `plugin/velocity` · `plugin/waterfall`

<Callout type="note">
  Individual marketplaces can be disabled per panel with the
  `MARKETPLACE_MODRINTH_ENABLED`, `MARKETPLACE_HANGAR_ENABLED` and
  `MARKETPLACE_SPIGET_ENABLED` environment variables. See [Environment
  Variables](/docs/hydrodactyl/config/envs).
</Callout>

## Subdomains

Add one of these features to have Hydrodactyl create a DNS record for the server automatically:

- `subdomain_minecraft`
- `subdomain_factorio`
- `subdomain_rust`
- `subdomain_scpsl`
- `subdomain_teamspeak`
- `subdomain_vintagestory`

See [Cloudflare Subdomains](/docs/hydrodactyl/subdomains/cloudflare) for details on configuring a DNS provider.

## Server console features

These features show a modal in the server console when the matching problem is detected:

- `eula` — offers to accept the Minecraft EULA, then restarts the server.
- `java_version` — lets the user switch Java versions when the server requires a newer one.
- `gsl_token` — prompts for a GSL token when the server reports an expired or missing one.
- `pid_limit` — offers to raise the process (PID) limit when the server hits thread-creation errors.
- `steam_disk_space` — offers to fix a SteamCMD server that needs more free disk space.
- `hytale_oauth` — shows a Hytale device-login link when the server needs to be authenticated.
- `mclogs` — analyses crashes through [mclo.gs](https://mclo.gs/) and shows a readable breakdown in the panel.

## Adding a feature to an egg

Features belong to the egg. To add one, edit the egg in the panel admin (**Admin → Nests →** select the nest **→** select the egg) and add the feature string to its **Features** field — or include it in the `features` array when importing an egg JSON.
